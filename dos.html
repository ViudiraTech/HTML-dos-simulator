HTML-DOS Keyboard Shortcuts

Command line

Left / RightMove the cursor (Ctrl = by word)
Home / EndJump to start / end of the line
Backspace / DeleteDelete before / under the cursor
InsertToggle insert (block cursor) / overwrite (underline)
Up / DownBrowse command history (100 entries)
F1 / F3Copy one character / the rest of the previous command
Tab / Shift+TabComplete command and file names (press again to cycle)
EscClear the current line
Ctrl+CAbort the command or batch file
F6 or Ctrl+ZEnd-of-file marker (for COPY CON)
Ctrl+LClear the screen
Shift+PgUp / PgDnScroll back through 1000 lines (or mouse wheel)
F12Show / hide this panel

Graphics programs (PLASMA, BALL)

EscReturn to the DOS prompt (screen is restored)
Arrows / Space / CBALL: gravity / add ball / clear

MARIO

Left / Right, A / DWalk
Down, SCrouch / enter pipe
Z or SpaceJump (hold for a higher jump)
X or ShiftRun
EnterStart / pause
EscQuit to DOS  (MARIO /M = no music)
